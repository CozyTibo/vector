# Artifact Linkage Model

## Objective
Link artifacts to discussions, decisions, actions, and ownership contexts.

## Link Types
- artifact discussed-in thread,
- artifact implements decision,
- artifact blocked-by concern,
- artifact owned-by actor/team,
- artifact depends-on artifact.

## Evidence Rules
- deterministic links from explicit refs and ids,
- inferred links remain non-authoritative with confidence.

## Temporal Rules
- linkage validity windows represent evolving relationships over time.
