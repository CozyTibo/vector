# Discussion Lineage Model

## Objective
Link discussion fragments into coherent lineage across channels and tools.

## Lineage Surfaces
- thread continuation,
- cross-reference links,
- artifact-linked discussions,
- escalation and blocker discussion chains.

## Lineage Rules
- explicit links create deterministic lineage edges,
- inferred continuation edges require confidence and ambiguity metadata,
- lineage retains temporal sequence and supersession.
