# Deterministic Linking Model

## Deterministic-Only Signals
- explicit references and identifiers,
- explicit mentions and assignment records,
- explicit repository/ticket/doc URLs,
- explicit ownership declarations,
- explicit cross-tool pointers in source payloads.

## Deterministic Boundaries
- no probabilistic inference in deterministic stage,
- no semantic guesswork where explicit evidence is absent.

## Deterministic Output Rules
- links are generated only when deterministic evidence threshold is met,
- deterministic links are marked as authoritative for this phase scope.
