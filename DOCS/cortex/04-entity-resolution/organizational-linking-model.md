# Organizational Linking Model

## Purpose
Connect canonical objects into coherent organizational continuity structures.

## Link Families
- people <-> initiatives,
- discussions <-> artifacts,
- decisions <-> actions,
- concerns <-> blockers,
- artifacts <-> execution threads,
- ownership <-> evolving initiatives.

## Linking Principles
- links require evidence and provenance,
- explicit deterministic links preferred,
- inferred links stay confidence-scoped and inspectable,
- conflicting links remain explicit until resolved.

## Value
Turns isolated canonical objects into navigable organizational topology.
