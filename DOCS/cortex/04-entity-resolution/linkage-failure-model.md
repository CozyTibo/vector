# Linkage Failure Model

## Failure Classes
- identity conflict explosion,
- linkage drift from version changes,
- confidence collapse,
- provenance discontinuity,
- replay divergence beyond thresholds,
- ontology mapping conflicts impacting linking.

## Handling Model
- quarantine invalid linkage batches,
- persist unresolved ambiguity rather than forced merge,
- block publication on provenance-critical failures,
- provide failure lineage and remediation guidance.

## Unacceptable Failures
- silent identity rewrites,
- hidden AI-only link creation,
- links without evidence/provenance.
