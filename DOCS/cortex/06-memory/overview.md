# Memory Derivation Layer Overview

## Why This Phase Exists
This phase isolates a specific transformation responsibility in the Cortex cognition pipeline so downstream intelligence remains deterministic, replayable, and explainable.

## Responsibilities
- Compression and rollup of canonical + graph memory
- Derived memory views for retrieval and reasoning
- Memory quality and compaction metadata

## Non-Responsibilities
- No source payload mutation
- No direct synthesis narratives
- No hidden confidence rewriting

## Ownership Boundary
This phase owns only its contract outputs and may not bypass adjacent layers.
