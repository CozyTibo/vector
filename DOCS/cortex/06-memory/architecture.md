# Memory Derivation Layer Architecture

## Input Contracts
- Canonical + graph artifacts
- Compaction policies
- Retention strategy

## Output Contracts
- Compressed memory
- Derived memory projections
- Memory health signals

## Allowed Logic
- Contract validation and schema version checks.
- Deterministic transformation inside declared ownership.
- Confidence annotation only when phase contract requires it.

## Forbidden Logic
- No source payload mutation
- No direct synthesis narratives
- No hidden confidence rewriting

## Dependency Boundary
This phase depends only on upstream-adjacent contracts and shared schema definitions. Direct dependency on non-adjacent phase internals is forbidden.
