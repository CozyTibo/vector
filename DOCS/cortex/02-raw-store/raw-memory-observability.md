# Raw Memory Observability

## Health Signals
- replay retrieval latency,
- archival rehydration success rate,
- provenance completeness ratio,
- corruption detection event count,
- raw storage growth and saturation trends,
- partition skew/imbalance indicators.

## Required Dashboards
- raw memory integrity dashboard,
- replay substrate health dashboard,
- archival accessibility dashboard,
- growth/cost trend dashboard.

## Required Alerts
- immutable hash drift,
- replay retrieval failure spikes,
- provenance continuity breaches,
- archive rehydration failure threshold breach,
- rapid storage saturation events.
