# Raw Storage Boundaries

## Raw Store Owns
- immutable source payload durability,
- deterministic source-grounded retrieval,
- replay foundational indexing and lineage,
- archival location and integrity cataloging.

## Raw Store Must Not Own
- semantic normalization,
- canonical relationship synthesis,
- organizational concept classification,
- semantic dedupe or clustering.
- identity resolution decisions,
- graph semantics or traversal intelligence,
- AI interpretation/reasoning artifacts.

## Boundary Enforcement
- only source and ingestion metadata fields are persisted.
- no writes from canonical/reasoning phases into raw tables.
- downstream layers consume raw data via read contracts, never mutate it.
