# Phase Transition Visualization

## Transition Objective
Show how data transforms phase-to-phase with visible lineage and trust indicators.

## Required Transition Nodes
- Raw Event -> Canonical Object -> (future) Graph -> (future) Reasoning outputs.

## Required Transition Metadata
- source refs and provenance chain,
- version tuple by transition step,
- ambiguity/confidence annotations,
- replay participation markers.

## Replay Visibility
- highlight replay-originated transitions,
- show divergence points between baseline and replay outputs.

## Human Readability
- each transition includes a plain-language explanation:
  - "input seen",
  - "transformation applied",
  - "output produced",
  - "confidence/trust status".
