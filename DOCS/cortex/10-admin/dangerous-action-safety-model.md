# Dangerous Action Safety Model

## Dangerous Actions
- tenant-wide replay,
- multi-phase reprocessing,
- queue flush with live impact,
- extraction invalidation across broad scope,
- ontology migration trigger,
- corruption quarantine impacting critical paths.

## Mandatory Safeguards
- blast radius preview,
- dependency impact summary,
- required approvals (dual-control for highest risk),
- dry-run/precheck where possible,
- rollback/recovery plan confirmation.

## Execution Rules
- dangerous actions are blocked without approval token.
- action execution emits high-fidelity audit event bundle.
- post-action verification is mandatory before trust state returns to healthy.
