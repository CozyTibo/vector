# Reprocessing Control Model

## Reprocessing Scope
- extraction rerun,
- canonicalization rerun,
- linking rerun,
- ambiguity re-evaluation rerun.

## Safe Reprocessing
- operates from immutable raw evidence.
- emits superseding outputs, not destructive mutations.
- preserves replay and provenance lineage.

## Dangerous Reprocessing
- workspace-wide semantic reprocessing,
- ontology-version migration reruns,
- cross-phase reprocessing chains.

## Required Controls
- scope preview,
- dependency impact map,
- trust-risk warning,
- approval and audit log requirements.
