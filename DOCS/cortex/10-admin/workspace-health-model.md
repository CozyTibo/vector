# Workspace Health Model

## Health Dimensions
- ingestion health,
- replay health,
- provenance continuity health,
- ambiguity pressure,
- extraction confidence stability,
- canonicalization drift risk,
- storage saturation risk.

## Composite Health Status
- `GREEN`: no critical risks.
- `YELLOW`: bounded degradation with safe operation.
- `RED`: trust-impacting failures requiring immediate intervention.

## Required Workspace Health Outputs
- current status and trend,
- dominant risk contributors,
- trust warning flags,
- prioritized remediation actions.
