# Ambiguity Review Model

## Objective
Provide human review workflow for unresolved semantic uncertainty.

## Ambiguity Review Objects
- uncertain entity linkage,
- uncertain ownership assignment,
- conflicting ontology mappings,
- conflicting semantic interpretations.

## Required Ambiguity View Fields
- ambiguity type,
- confidence score/band,
- competing candidates,
- supporting and conflicting evidence refs,
- replay impact and downstream dependency impact.

## Review Actions
- accept candidate,
- defer with reason,
- request reprocessing scope,
- escalate for ontology review.

## Trust Rule
Ambiguity remains explicit unless resolved through approved evidence-backed workflow.
