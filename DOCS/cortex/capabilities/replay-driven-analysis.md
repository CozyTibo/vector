# Replay-Driven Analysis Capability

Replay-driven analysis uses controlled regeneration to test architecture and cognition stability.

## Capability Scope

- compare outputs across extraction/ontology versions,
- detect linkage drift and interpretation drift,
- quantify stability of key conclusions,
- validate migration and schema evolution safety.

## Required Primitives

- replay lineage identifiers,
- generation diff tooling,
- scoped replay execution controls,
- cost-aware replay planning,
- confidence/provenance delta reporting.

## Operational Value

Replay-driven analysis prevents silent semantic regression as Cortex evolves.
