# Strategic Analysis Capability

Strategic analysis in Cortex is bounded organizational reconstruction, not executive omniscience.

## Supported Strategic Questions

- where initiative execution drifts repeatedly,
- which dependency zones become chronic hotspots,
- what coordination failure patterns recur,
- how execution topology changes across periods.

## Boundaries

- Cortex can reveal reconstructed patterns.
- Cortex cannot guarantee policy-optimal decisions without human governance.

## Required Primitives

- multi-period temporal aggregation,
- continuity-preserving initiative topology,
- confidence-aware pattern scoring,
- uncertainty surfaces for sparse/noisy segments.

## Risks To Avoid

- mistaking correlation for causation,
- collapsing ambiguity into false certainty,
- over-generalizing from incomplete memory slices.
