# Operational Debugging Capability

Operational debugging treats organizational execution as a debuggable system.

## Debug Workflows

- replay execution timelines for specific windows,
- inspect blocker propagation paths,
- trace ownership instability causes,
- reconstruct coordination breakdown points,
- compare current vs replayed interpretations.

## Required Primitives

- admin control plane with phase visibility,
- replay orchestration and scoped reruns,
- provenance drill-down tools,
- temporal diffs and ambiguity inspection.

## Operator Trust Contract

Operators must see what was observed, what was inferred, and what changed between generations.
