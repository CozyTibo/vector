# Unresolved Capability Gaps

These are architecture limitations that currently block realistic end-state capabilities.

## 1) High-Confidence Causal Reasoning

- **Gap:** architecture can reconstruct sequences, but causal attribution boundaries are still weak.
- **Blocks:** incident analysis, strategic analysis.
- **Missing primitives:** explicit causal hypothesis model, counterfactual discipline, confidence taxonomy for causality.

## 2) Large-Scale Temporal Graph Traversal Economics

- **Gap:** deep temporal + dependency traversal costs are not fully bounded.
- **Blocks:** dependency intelligence, historical reconstruction, execution intelligence.
- **Missing primitives:** query materialization policy, hot/cold temporal indexes, traversal budgets.

## 3) Initiative Split/Merge Continuity Semantics

- **Gap:** continuity model for initiative renames, splits, merges, and ownership migration is under-specified.
- **Blocks:** initiative continuity, onboarding intelligence, strategic analysis.
- **Missing primitives:** continuity lifecycle ontology + conflict resolution policy.

## 4) Ambiguity Lifecycle Governance

- **Gap:** ambiguity exists as concept but closure/escalation lifecycle is not fully operationalized.
- **Blocks:** trust in copilots/search/synthesis outputs.
- **Missing primitives:** ambiguity state machine, operator decision hooks, SLA for unresolved ambiguity.

## 5) Replay Cost and Diff Tooling

- **Gap:** replay is foundational but economics and operator-grade diff tooling remain immature.
- **Blocks:** replay-driven analysis, operational debugging, safe ontology evolution.
- **Missing primitives:** replay budget policy, selective replay planner, diff severity classification.

## 6) Retrieval + Synthesis Trust Contract

- **Gap:** retrieval and synthesis phases are planned but not yet operationally constrained for overclaim prevention.
- **Blocks:** copilots, strategic analysis, onboarding intelligence.
- **Missing primitives:** citation completeness checks, synthesis guardrails, uncertainty-aware answer policy.

## 7) Organizational Topology Inference Limits

- **Gap:** topology reconstruction (actual coordination structure vs org chart) lacks formal confidence criteria.
- **Blocks:** historical reconstruction, dependency intelligence, strategic analysis.
- **Missing primitives:** topology inference rules, evidence thresholds, confidence decay over sparse periods.

## 8) Cross-Phase Validation Harness

- **Gap:** no permanent capability-level test harness validates end-state scenarios against architecture changes.
- **Blocks:** regression detection for long-horizon cognition capabilities.
- **Missing primitives:** capability benchmark corpus, phase-gated capability tests, readiness drift alarms.
