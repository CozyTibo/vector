# Dependency Intelligence Capability

Dependency intelligence reconstructs and monitors the real dependency topology of execution.

## Capability Set

- dependency chain reconstruction,
- blocker propagation tracking,
- fragility hotspot detection,
- hidden coupling discovery,
- dependency ownership ambiguity detection.

## Required Primitives

- dependency ontology maturity,
- temporal graph evolution,
- cross-tool artifact linkage,
- provenance-backed dependency edges,
- scalable traversal/query infrastructure.

## Trust Constraints

Dependency insights must include:

- source evidence,
- inferred-edge confidence,
- affected timeline windows,
- unresolved ambiguity markers.
