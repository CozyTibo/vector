# Ontology Dependency Map

## Purpose
This map identifies which ontology concepts are foundational dependencies for graph, memory, reasoning, retrieval, and synthesis behavior.

## Project
- Depends on: ownership, milestone, dependency, artifact.
- Enables:
  - graph: project dependency and delivery edges,
  - temporal reasoning: project evolution timeline,
  - memory: project state rollups,
  - retrieval/synthesis: execution status narratives.

## Initiative
- Depends on: project, milestone, decision.
- Enables:
  - graph: initiative-to-project hierarchy,
  - reasoning: strategic intent lineage,
  - synthesis: cross-project progress interpretation.

## Decision
- Depends on: discussion, thread, concern, artifact.
- Enables:
  - graph: decision supersession and consequence edges,
  - temporal reasoning: decision evolution,
  - causal reconstruction: decision -> outcome pathways.

## Concern
- Depends on: discussion/thread evidence and actor attribution.
- Enables:
  - reasoning: uncertainty and blocker signals,
  - memory: unresolved/resolved concern lifecycle,
  - synthesis: risk-aware summaries.

## Dependency
- Depends on: project/artifact/entity relations.
- Enables:
  - graph: blocking/depends_on topology,
  - causal reasoning: execution bottleneck reconstruction,
  - retrieval: dependency-focused context selection.

## Ownership
- Depends on: actor/team entity stability and temporal validity.
- Enables:
  - graph: ownership transition edges,
  - reasoning: accountability lineage,
  - synthesis: owner-of-record explanations.

## Thread
- Depends on: discussion event linkage and chronology.
- Enables:
  - graph: thread continuity edges,
  - memory: discussion compaction,
  - reasoning: intent and concern emergence over time.

## Discussion
- Depends on: source events, participants, channels/artifacts.
- Enables:
  - canonical event normalization,
  - thread and topic extraction,
  - decision evidence chains.

## Artifact
- Depends on: source object identity mapping and canonical entity linkage.
- Enables:
  - graph: artifact-project/decision/dependency edges,
  - memory: artifact-centric retrieval clusters,
  - synthesis: evidence grounding.

## Milestone
- Depends on: project/initiative timeline and status transitions.
- Enables:
  - temporal reasoning: planned-vs-actual progression,
  - causal reconstruction: missed milestone diagnostics,
  - synthesis: execution checkpoint narratives.

## Foundational Dependency Notes
- If ontology definitions drift, graph typing and reasoning semantics drift immediately.
- Ontology stability is a prerequisite for implementation in `03-canonical` onward.
