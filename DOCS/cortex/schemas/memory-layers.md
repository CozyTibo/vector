# Memory Layers

## Layer 1: Raw Memory
Immutable source event payloads and ingestion metadata.

## Layer 2: Compressed Memory
Compacted representations of canonical events and threads for efficient reconstruction.

## Layer 3: Derived Memory
Rollups, aggregates, and projection tables supporting operational queries.

## Layer 4: Semantic Memory
Embedding/index structures and semantic metadata used for retrieval assistance.

## Layer 5: Temporal Memory
Time-ordered causal chains, decision lineage, and execution evolution constructs.
