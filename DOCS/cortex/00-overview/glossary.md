# Glossary

## Raw Event
Immutable, source-faithful representation of a fetched payload plus ingestion metadata.

## Canonical Event
Tool-agnostic event representing organizational activity using normalized schema.

## Canonical Entity
Normalized actor, team, project, artifact, topic, decision, or thread identity.

## Canonical Relation
Typed edge describing relationships between canonical entities/events over time.

## Memory Layer
Derived representation optimized for retrieval, reasoning, and synthesis while preserving lineage.

## Context Pack
A bounded, evidence-grounded bundle of memory objects selected for a query or synthesis task.

## Ambiguity Boundary
A point where deterministic methods cannot safely infer meaning; AI may be invoked with explicit confidence handling.

## Replay
Re-execution of one or more layers from preserved immutable events using current or historical processor versions.

## Temporal Lineage
Ordered causal and state transition chain across events, entities, and decisions.
