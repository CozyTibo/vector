# Cortex Anti-Goals

## Cortex Is Not
- an autonomous agent platform,
- a prompt-only memory mechanism,
- a vector-search-only architecture,
- an opaque AI scoring service,
- a hidden-reasoning black box,
- a tool-specific analytics silo,
- a giant-context-window workaround.

## Explicit Rejections
- No "AI decides truth" design.
- No connector-side organizational inference.
- No unversioned inference artifacts.
- No synthesis output without provenance and uncertainty semantics.

## Drift Prevention Rule
Any proposed feature that violates these anti-goals requires an ADR and explicit architecture review before planning.
