# Linkage Query Optimization

## Objective
Improve linkage/continuity query responsiveness while preserving explainability and evidence integrity.

## High-Pressure Linkage Queries
- cross-tool actor continuity lookups,
- initiative continuity across artifacts and decisions,
- ambiguity branch inspection and resolution history.

## Candidate Optimizations
- adjacency summaries for common traversal depths,
- time-window continuity snapshots,
- conflict-set indexes for ambiguity triage,
- scoped neighborhood caches for repeated operator investigations.

## Risks
- opaque linkage shortcuts that bypass provenance,
- stale continuity snapshots after replay,
- cache invalidation complexity across phases.

## Guardrail
Linkage optimizations are acceptable only when provenance reachability and replay-safe recomputation are guaranteed.
