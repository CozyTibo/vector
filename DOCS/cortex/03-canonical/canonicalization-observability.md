# Canonicalization Observability

## Health Signals
- canonicalization throughput and latency,
- deterministic extraction failure rates,
- AI-assisted extraction invocation and failure rates,
- ambiguity open/resolved ratios,
- provenance completeness ratio,
- replay divergence rates.

## Required Alerts
- provenance propagation failures,
- schema/ontology mismatch spikes,
- confidence collapse trend,
- replay divergence anomaly.

## Operator Views
- per connector/tenant canonicalization health,
- ambiguity backlog and confidence distribution,
- replay comparability reports.
