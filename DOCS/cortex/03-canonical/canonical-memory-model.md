# Canonical Memory Model

## Purpose
Canonical memory provides normalized organizational structure for downstream linking, graph, retrieval, and reasoning while remaining provenance-grounded.

## Canonical Objects
- canonical events,
- canonical entities,
- canonical relations,
- canonical topics,
- canonical threads/discussions,
- canonical artifacts,
- canonical decisions,
- canonical actions,
- ownership/dependency references.

## Properties
- tool-agnostic,
- provenance-preserving,
- temporally grounded,
- replay-compatible,
- confidence-aware where inference is involved.

## Memory Trust Boundary
- deterministic canonical facts are distinct from inferred annotations.
- inferred canonical fields must always include confidence and evidence references.
