# Canonicalization Consistency Model

## Strong Consistency Required
- canonical object identity uniqueness,
- provenance attachment completeness,
- deterministic extraction field persistence.

## Eventual Consistency Acceptable
- aggregate canonicalization metrics,
- non-critical observability rollups.

## Replay Consistency
- fixed input + version tuple yields reproducible canonical outputs.
- any divergence must be explainable by version or scope changes.
