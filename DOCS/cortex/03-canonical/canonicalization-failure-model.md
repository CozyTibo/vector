# Canonicalization Failure Model

## Failure Classes
- deterministic extraction parse failure,
- ontology mapping conflict,
- ambiguity explosion (unbounded unresolved states),
- provenance discontinuity,
- temporal propagation mismatch,
- replay divergence beyond expected bounds,
- AI extraction degradation.

## Failure Handling
- quarantine malformed transformation units.
- preserve partial successful deterministic outputs with clear status.
- block publication when provenance integrity fails.
- downgrade to ambiguity records when AI confidence insufficient.

## Unacceptable Failures
- canonical writes without provenance,
- raw mutation attempts,
- silent collapse of conflicting interpretations into single certainty.
