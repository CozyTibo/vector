# Canonicalization Evolution

## Evolution Drivers
- ontology expansion,
- mapping strategy refinement,
- deterministic extractor improvements,
- AI inference model updates,
- schema enhancements.

## Safe Evolution Rules
- all changes are versioned and replay-assessed.
- old outputs remain auditable.
- supersession preserves temporal and provenance continuity.

## Evolution Risk Controls
- replay divergence verification required after version changes.
- ambiguity and confidence drift tracked across versions.
