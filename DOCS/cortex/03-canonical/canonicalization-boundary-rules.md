# Canonicalization Boundary Rules

> **Normative supersession:** Hard boundaries live in `phase-03-deterministic-canonicalization-doctrine.md` + `phase-03-anti-goals-doctrine.md`. Confidence classes live in `phase-03-ambiguity-confidence-doctrine.md`.

## Canonicalization May
- normalize **structure** into ontology-aligned canonical objects per versioned mapping tables,
- extract deterministic references and explicit structured state,
- register ambiguities and **explicit** confidence labels allowed by doctrine (no probabilistic identity merges).

## Canonicalization May Not
- produce strategic judgments,
- perform causal inference,
- generate executive summaries,
- reinterpret raw truth without provenance,
- bypass deterministic-first extraction.

## Boundary Leakage Prevention
- no downstream reasoning logic imported into canonicalization.
- no synthesis-oriented narrative generation at canonical layer.
- no AI usage outside documented ambiguity boundaries.
