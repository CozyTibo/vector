# Canonicalization Layer Architecture

> **Normative supersession:** Structural boundaries, anti-goals, the **18-stage** execution program + **operator co-evolution track**, and **canonical control plane** obligations live in `phase-03-normative-index.md`, `phase-03-anti-goals-doctrine.md`, `implementation-plan.md`, and `phase-03-canonical-control-plane-doctrine.md`.

## Mission
Deterministically transform Phase 02 raw organizational memory into tool-agnostic **canonical structural primitives** while preserving provenance, temporal semantics, replayability, and **explicit ambiguity**—**without** semantic inference.

## Owns
- structural normalization of raw envelopes,
- deterministic extraction of **evidenced** structured fields (E0/E1 grades),
- versioned ontology/mapping slices via the **mapping bundle registry** (`phase-03-mapping-bundle-registry.md`),
- ambiguity registration and confidence annotation as **first-class structural metadata**,
- canonical persistence contracts + replay/rebuild orchestration,
- verification + control-plane surfaces per tracker Steps **16–18**.

## Does Not Own
- causal inference,
- strategic interpretation,
- executive synthesis,
- decision quality judgment,
- graph traversal intelligence.

## Input Contracts
- immutable raw events with source identity/version/provenance bootstrap fields,
- ontology definitions and mapping registry,
- extraction policy/version bundle.

## Output Contracts
- `CanonicalEvent`, `CanonicalEntity`, `CanonicalRelation`,
- canonical model projections (`Topic`, `Thread`, `Artifact`, `Decision`, `Action`),
- ambiguity records,
- provenance and confidence fields.

## Core Guarantees
- deterministic-first extraction pipeline (no clock/random canonical identities),
- no mutation of raw truth,
- replay-comparable canonical outputs under pinned mapping bundles + declared engine builds,
- strict boundary between evidenced structure and **unresolved** states (ambiguity records—not guessed hypotheses).
