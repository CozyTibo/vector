# Implementation Ordering

## Ordering Principles
- Prioritize correctness and replayability over feature breadth.
- Build infrastructure memory layers before interaction layers.
- Delay AI-heavy paths until deterministic baselines are stable.

## Practical Ordering
1. Data contracts
2. Persistent event pipelines
3. Canonical and identity layers
4. Graph and memory derivation
5. Reasoning and retrieval
6. Synthesis and operator tooling
